【创意方案】

听见你——声音优先的无障碍交友

【作品简介】

听见你不是给视障用户做一个“特殊版交友软件”，而是把声音变成认识彼此的主入口，主要面向视障、低视力、照片焦虑和低社交电量人群。

用户用四段真实回答介绍自己：最近开心的小事、理想中的一个下午、希望朋友怎样相处、想尝试的新事情。系统根据共同兴趣、关系期待、交流方式、小组偏好和无障碍需求给出可核对的推荐理由，不依据照片排名，也不推测人格。

双方确认后，平台生成可朗读的公共空间见面卡，提供无障碍路线、30 分钟轻柔提醒和无需解释的离场方式，把一次匹配变成安全的现实连接。

当前 Web 原型已实现完整三步流程、浏览器录音、可选语音转写、透明匹配、高对比与键盘操作，并部署在 GitHub Pages。AI 在正式版中只辅助文字摘要、破冰建议和活动安排，不改声、不代聊，也不替用户作决定。
